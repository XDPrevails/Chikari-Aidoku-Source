
# Chikari Aidoku Source

Manga reader for Chikari.moe on Aidoku.

## Installation

1. Download the latest `package.aix` from the [releases](https://github.com/xdprevails/Chikari-aidoku-source/tree/main/docs)
2. Open the file with Aidoku on your Phone
3. The source will be installed/updated
